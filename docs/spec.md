# だんごくんの大冒険 仕様メモ

依頼: 代表の友達わたあめちゃんのゲーム（2026-11-01 録音ヒアリング「わたあめちゃんゲーム企画」より）。

## 決まったこと
- タイトル: だんごくんの大冒険（だんごくんはひらがな）
- 遊ぶ機械: iPad の横画面（ブラウザで開く）
- お手本の雰囲気: マップは3D・コースに入ると2Dの横スクロール（今は2Dのコース部分から作る）
- 主人公 だんごくん: 真ん丸・ふちがふわふわ・うすい水色・足/手/しっぽなし・目は棒・目の間に ω の口（2026-11-01 決定）
- なかま うさぎさん: 白・2本足で立つ・手は体の横にたらす・目は藍色がかった黒（2026-11-01 決定）
- 集める物: お星さま
- ゴール: 雲の世界でうさぎさんが待っている
- コース数(仮): レベル1〜5 × 3コース = 15コース → 2026-11-01 15コース作成（代表「クリアしても同じコースしかない。大量に増やして」）

## 試作（レベル1-1）で決めた動き(仮)
- 敵は上から踏むと消える。横から当たると押し戻されて少し点滅（やられて終わりにはしない）(仮)
- 穴に落ちたらチェックポイントからやり直し。ゲームオーバーなし (仮)
- 速さ・ジャンプの高さは index.html 先頭の CONFIG で調整
- 音はまだ入れていない → 2026-11-01 音楽と効果音を追加（下記）

## 楽しくする仕掛け（2026-11-01 代表「楽しくする案を考えて取り入れて」「音楽もつけて」で孫悟空が追加。わたあめちゃんの希望ではないので、いやなら外す）
- 星のブロック（B）: 下からたたくとお星さまが出る。普通のブロックは点の模様、星のブロックは白い星の模様
- ぽよーん雲（J）: ピンクの雲。乗ると高く跳ねる。高い所の お星さま・おおきなお星さま に届く
- おおきなお星さま（O）: 1コースに3つ。左上とゴール画面に集めた数。取り残すと「まだ かくれているよ」
- たすけ雲: 同じ区間（旗と旗の間）で2回落ちたら、次からは穴の底で雲が押し上げてくれる (仮)
- 音楽: オリジナルの明るい8小節をくり返す（ファイルを使わずその場で鳴らす）。ゴールでファンファーレと星の花火
- 効果音: ジャンプ・お星さま・ブロック・ぽよーん・踏む・旗。右上の 🔊 で音楽と効果音をまとめて消せる（設定は残る）
- さいこう記録: いちばん多く集めた数をタイトルに出す（その iPad の中だけに残る）
- 演出: 着地のけむり、速く走るとキラキラ、「ぽよん」「+1」などの文字

## オープニング（2026-11-01 代表「オープニングもあった方がいい」）
- 起動するとタイトルの前に約14秒のおはなし。タップでとばせる。おはなしの中身は孫悟空の案（いやなら直す）
  1. だんごくんと うさぎさんが そうげんで あそぶ
  2. 雲が降りてきて うさぎさんを乗せて空へ「くもの せかいで まってるね！」（さらわれる・こわい話にはしない）
  3. お星さまの道が出て「お星さまを あつめながら くもの せかいへ しゅっぱつ！」
- 縦向きの表示は「がめんを よこむきに してね」（iPad 以外でも通じるように）
- iPad で勝手に右へ動く不具合を直した（指を離した知らせが来ない時の対策、画面の上半分はボタンとして受けない）

## ハート（2026-11-01 代表B）
- ハート3つ。敵に横から当たると1つ減る（押し戻されて少し点滅）。0になると旗からやり直し、ハートは3つにもどる。ゲームオーバーなし
- 集めたお星さまはやり直しても減らない。旗を通るとハートが元にもどる（孫悟空の案）
- 穴に落ちたときはハートは減らず、今までどおり旗にもどる (仮)
- 数は index.html 先頭の CONFIG.hearts

## 進化と武器（2026-11-01 代表C）
- 取ると進化：見た目が変わり、まわりを小さなお星さまが回る。見た目は ③きんいろ に決定（2026-11-01 代表）。CONFIG.powerLook = 'gold'
- 進化中は「なげる」ボタンが出る（ジャンプの左）。押すと向いている方へお星さまがはずみながら飛び、敵に当たると倒す。同時に2つまで。キーボードは X / F / Enter
- 武器は4種類（2026-11-01 代表「武器も種類増やして」）。アイテムは光る玉の中に武器のしるし。取るとその武器で進化（進化中に別のを取ると持ちかえ）。各コース3つ、コースごとに出る順番が変わる
  - お星さま：はずみながら進む（同時に2つ）
  - しゃぼんだま：ゆっくりふわふわ進み、敵をつつんで空へ（同時に3つ）
  - わたあめ：山なりに投げ、落ちた所でふわっと広がってまわりの敵をまとめて倒す（1つ）
  - ブーメラン：行ってもどってくる。壁も通りぬけ、とちゅうの敵をぜんぶ倒す（1つ）
- 進化中に敵に横から当たると、ハートは減らずに元の姿にもどる
- 進化はコースをまたいでも続く（ページを開き直すと元にもどる）(仮)

## 敵の種類とボス（2026-11-01 代表「敵の種類も増やして。各ステージにボスもいるといいね」）
- 敵4種類（絵と名前は孫悟空の案。わたあめちゃんの希望があれば直す）。コースが進むと増える（1-1 は ぷにぷに だけ → 1-2,1-3 で ぴょんぴょん → レベル2 で ぱたぱた → レベル3〜 とげとげ）
  - ぷにぷに（むらさき）：歩く ／ ぴょんぴょん（みどり）：歩きながら跳ねる ／ ぱたぱた（ピンク・羽）：ふわふわ飛ぶ ／ とげとげ（茶色）：上から踏めない（武器で倒す・よける）
- ボス：全コースのゴール手前に「ボスの広場」（平らな18マス）。倒すまでゴールへ進めない。上から踏む・武器を当てると体力が1減る（当たった後0.9秒は効かない）
  - レベル1 おおきな ぷにぷに（だんごくんの方へ跳ぶ）／2 どんぐり だいおう（ぶるぶるしてから突進）／3 はさみ がに（横に速く歩く）／4 ゆきだるま（雪玉を山なりに投げる）／5 もくもく ぐも（空から雨つぶ・ときどき降りてくる＝踏むチャンス）
  - 体力 3〜6（レベルが上がると増え、各レベルの3つ目のコースは +1）。体力は画面上に名前とバーで出る
  - やられて旗にもどっても、ボスの体力はそのまま (仮)

## 絵の作り込み（2026-11-01 代表A）
- 背景を3層（遠くの山・中の丘・近くの丘）にして速さを変え奥行きを出した。景色ごとに 木・もみの木・島と海・ほたる・木もれ日
- 地面は深いほど濃く、崖の縁に光と影、草のふちは波形、小石。飾りは 花／きのこ／貝がら／雪のきらきら／光る石
- ブロックに光と影、星のブロックは金色でまわりにきらきら。お星さまは金のグラデーション
- だんごくん・うさぎさんは決めた形のまま、光沢とかげ、足もとの影を足した
